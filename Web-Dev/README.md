# Student Management System

A beginner-friendly Student Management System built with **HTML and CSS**.

## Features
- Dashboard cards: total students, active students, courses and average age
- Add new student records
- Edit existing student details
- Delete student records (with confirmation)
- Search by student name, roll number, course or email
- Filter by course and active/inactive status
- Form validation and duplicate roll-number checking
- Saves data in browser `localStorage`
- Responsive layout for desktop and mobile
- Includes three sample student records on first launch

## How to run
1. Extract `student-management-system.zip`.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
4. Click **Add Student** to add your own records.

No installation or server is required.

## Project files
- `index.html` — page structure and student form
- `style.css` — layout, colors and responsive design


## Important note
This is a frontend learning project. Data is stored only in the current browser on the current device. It does not yet have a login system, database, or cloud backup. Clearing browser site data can remove saved records.
